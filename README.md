# Aditya & Shreya — Royal Hindu Wedding Invitation V3

This is a static mobile-first wedding invitation website.

## Deploy on Vercel
- Upload the contents to a GitHub repository
- Import the repo in Vercel
- Framework preset: Other
- No build command required

## Notes
- Calendar downloads are implemented as .ics files
- Background soundtrack is included in assets/
- Best experienced on a mobile phone with sound enabled
